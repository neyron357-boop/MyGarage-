# AGENTS.md — MyGarage

Для любого агента, который работает с этим репозиторием. Сначала прочитай этот файл, затем `CLAUDE.md`
(жёсткие правила проекта: деньги, документы, неизменяемые записи, дизайн-система, команды) и документы задачи
в `docs/` (`docs/02` — сценарии, `docs/03` — экраны, `docs/04` — данные, `docs/progress.md` — что сделано,
`docs/quality/map.md` — карта экранов, жестов и дефектов).

## Стандарт качества MyGarage

Приложение — рабочий инструмент менеджера автомастерской. Целевое устройство — **iPhone 13** (390×844 pt, iOS 26),
основные режимы — **установленная PWA** и **Mini App внутри Telegram**. Ориентир поведения — системные приложения
iOS и Liquid Glass; Apple: [Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/),
[Build a UIKit app with the new design](https://developer.apple.com/videos/play/wwdc2025/284/).

### Стандарты, по которым работаем

- **Жесты и движение — [emilkowalski/skills](https://github.com/emilkowalski/skills).** Перед изменением жеста или
  анимации прочитать `skills/gestures/SKILL.md` и `skills/review-animations/STANDARDS.md`; для оболочки PWA —
  `skills/mobile-native/SKILL.md`, для рывков — `skills/animation-performance/SKILL.md`, для худших данных (длинные
  имена, пустые списки) — `skills/break-ui/SKILL.md`. Значения (кривые, длительности, пружины) берутся оттуда, не
  «на глаз».
- **Ревью интерфейса — [pbakaus/impeccable](https://github.com/pbakaus/impeccable)** (`.agents/skills/impeccable/`):
  `reference/audit.md` (доступность, производительность, темы, адаптивность, сломанное касание), `reference/critique.md`
  с `critique-rubric.md` (UX-оценка), `reference/polish.md` (последний проход), `reference/ios.md` (ожидания iPhone).
  Режим поверхности у MyGarage — **Operate**: точность и сдержанность, привычные паттерны iOS. Лаунчер
  `scripts/impeccable` скачивает и запускает бинарник — без явного согласия пользователя его не запускать; работать
  по справочникам (это предусмотренный путь «Launcher unavailable»).
- **Motion — [motiondivision/motion](https://github.com/motiondivision/motion)** (пакет `motion`, версия закреплена
  точно), **там, где он упрощает реализацию**: пружина, которую палец перехватывает с текущей скоростью, и доводка на
  композиторе (WAAPI), пока главный поток занят. Не переписывать на Motion то, что уже работает на CSS/WAAPI, пока
  компонент не меняется по задаче; при изменении — сравнить (строки кода, размер сборки, поведение) и записать решение
  в таблицу ниже.

### Порядок работы над изменением (обязателен для общих компонентов)

1. **Прочитать** `AGENTS.md`, `CLAUDE.md`, документы задачи и стандарты выше; найти все места, где общий компонент
   используется.
2. **Сначала — текущее поведение на телефоне.** Пройти путь касаниями до правок: Playwright с эмуляцией iPhone 13
   (`hasTouch`, события касания через CDP `Input.dispatchTouchEvent`) и запись «до» (`node e2e/gestures.cjs`); если
   доступен iPhone — то же на нём (сборка по локальной сети, см. ниже). Каждый дефект — в `docs/quality/map.md`: как
   воспроизвести, что сейчас, как должно быть, чем проверить.
3. **Причина, а не симптом** (obra/superpowers `systematic-debugging`): не исправлять, пока причина не найдена и не
   подтверждена замером.
4. Большая работа — **план** (`writing-plans`) в `docs/quality/`.
5. **Исправление в общем компоненте** по правилам ниже; совместимость с данными и рабочими сценариями сохраняется.
6. **Матрица жеста — для каждого изменённого жеста**, автотестом с касаниями (как в `e2e/motion.cjs`, раздел 12):
   - медленное движение — элемент под пальцем на каждом шаге (±1 px);
   - пауза — не уползает, пока палец стоит;
   - смена направления — без скачка;
   - отмена (`pointercancel`, отпустили вдали, системный жест) — согласованное состояние, действия нет;
   - новый захват во время анимации — подхват с текущего места, без прыжка;
   - а также быстрый жест (срабатывает только итог), тап против перетаскивания, касание не по центру и мимо элемента,
     «Уменьшение движения», несохранённые правки, если жест уводит с экрана;
   - для кнопок и листов — двойной тап (60–300 мс) по каждой кнопке, которая меняет то, что под пальцем, и повторный
     клик по кнопке уходящего листа (`e2e/motion.cjs` §14). Тесты кликают в темпе человека — не чаще раза в 400 мс
     (`e2e/smoke.cjs` задаёт это сам): быстрее сторож `ui/tapGuard.ts` справедливо гасит тап по кнопке, которую
     человек ещё не успел прочитать.
7. **Проверка** (`verification-before-completion` — без свежего вывода команды ничего не заявлять): матрица жеста;
   запись «после» тех же жестов; `npm run typecheck`, `npm test`, `npm run e2e` (и `E2E_HAPTIC_LABELS=1`),
   `npm run e2e:motion`, `npm run build`, `npm run moves` при изменениях стека и вкладок.
8. **Ревью тремя взглядами** (`requesting-code-review`, отдельными агентами, по диффу, не по моим выводам):
   код и QA (состояния жеста, iOS WebKit, Android Chrome, Telegram, VoiceOver, утечки); движение — по
   `review-animations` Эмиля Ковальски (таблица «Было / Стало / Почему» и вердикт Block/Approve); интерфейс — по
   Impeccable `audit` и `critique`/`polish` для изменённых экранов. Найденное исправить или записать в карту.
9. **Отчёт** — раздельно: подтверждено в браузере (эмуляция iPhone 13), в PWA на iPhone, в Telegram на iPhone.
   Статус на устройстве открыт, пока его не проверили на телефоне.

### Правила жестов и движения (из стандартов выше, применительно к MyGarage)

- **Две фазы жеста.** Пока палец на экране — элемент и есть палец: положение 1:1, без пружин, переходов и
  длительностей; у края — резина. После отпускания — физика: пружина со скоростью отпускания. Положение пишется в
  `transform` самого элемента (не CSS-переменной на родителе) и не через состояние React.
- **Отскок — только после жеста.** Отпустили после перетаскивания — лёгкий отскок (bounce 0,1–0,3). То же движение от
  тапа или ссылки — без отскока: силы не было. Возврат при отмене — быстрый.
- **Прерываемость.** Никаких `@keyframes` у того, к чему прикасается палец; доводка — пружина (Motion) или
  CSS-переход, которые подхватываются с текущего состояния.
- **Жесты различаются предсказуемо.** Тап — сдвиг меньше 8 px; перетаскивание — от 8 px, ось фиксируется по первому
  движению, захват указателя — только когда тап стал перетаскиванием; долгое нажатие — 450 мс без сдвига больше
  10 px; второй палец во время жеста игнорируется; вертикальная прокрутка не перехватывается горизонтальными жестами.
- **Действие — на отпускании, ровно один раз**; промежуточные положения ничего не открывают. Уход с экрана жестом
  спрашивает про несохранённые правки так же, как тап (`mayLeave` из `ui/unsaved.tsx`).
- **Кнопки.** Отклик нажатия в том же кадре (`:active`, сжатие 0,95–0,98 за 100–160 мс). Долгая операция — состояние
  загрузки сразу (`loading={busy}`); действие, повтор которого создаёт вторую запись (заказ, оплата, долг), —
  `useAction({ exclusive: true })`. Общий запрет повтора для всех `useAction` не включать: сохранение поля при уходе
  фокуса и чип, нажатый тем же касанием, идут одновременно — запрет потерял бы ввод.
- **Длительности и кривые.** Интерфейс — до 300 мс (листы и окна до 500 мс, кривая `--ease-ios`); появление и уход —
  `ease-out`-кривые, `ease-in` в интерфейсе не использовать; ничего не появляется из `scale(0)`.
- **Стабильность оболочки.** Нижняя панель и шапка не прыгают; поля и главные кнопки видны при клавиатуре; «Назад»
  возвращает на то место списка, откуда был открыт экран.
- **Плавность.** 60 fps на доске с десятками заказов и фото: transform/opacity, без раскладки на кадр, без
  `backdrop-filter` над прокручиваемым (кроме стекла панелей); то, что должно двигаться, пока строится новый экран, —
  на композиторе (WAAPI/Motion), не в rAF главного потока. При рывке — замер (`npm run moves`, Performance), причина,
  исправление.
- **«Уменьшение движения».** Жесты по-прежнему следуют за пальцем; пружины, отскоки и декоративные анимации уходят,
  цвет и прозрачность остаются.
- **Касание.** Цели от 44 pt; hover-эффекты — только под `@media (hover: hover) and (pointer: fine)`; тактильный
  отклик — только `ui/haptics.ts` (на iPhone — лишь от настоящего тапа по метке, из кода нельзя).

### Общие средства движения и жестов (и почему они такие)

| Что | Где | Почему так |
|---|---|---|
| Панель вкладок | `ui/tabBar.tsx` | Линза — Motion (`animate` по `x`/`scaleX`/`scaleY`): пружина отпускания идёт на композиторе (WAAPI) и не стоит, пока строится новая вкладка (своя rAF-пружина при CPU ×4 стояла до 234 мс), а при перехвате Motion снимает текущие положение и скорость. Под пальцем — `animate(..., { duration: 0 })` на каждое движение; линза не под пальцем (касание не по центру, мимо неё) доходит под него за ~200 мс. Захват указателя — только когда тап стал перетаскиванием (иначе клик уйдёт панели), «потерю захвата» кнопкой не считать отменой; отпускание слушается на `window`. `touchmove` на панели гасится: замерено — с одним `touch-action: none` Chrome принимает быстрый свайп за бросок и съедает следующий тап ~2 с. |
| Стек экранов, «Назад», свайп от края | `ui/stack.tsx` | Экран под пальцем — настоящий, не снимок (WAAPI). |
| Свайп строки | `ui/swipe.ts` | Порог, фиксация оси, кнопка действия. |
| Долгое нажатие | `ui/longPress.ts`, `ui/photoPick.tsx` | Таймер + отмена сдвигом; выбор файла — на отпускании (iOS открывает его только в касании). |
| Перетаскивание строк | `ui/sortable.ts` | Ручка ≡, захват указателя, строки расступаются. |
| Потянуть, чтобы обновить | `ui/pullRefresh.tsx` | Резина iOS, жест забирается на первом движении. |
| Анимация списков | `ui/motion.ts` (`useAutoAnimate`) | FLIP на WAAPI; не анимирует на скрытом экране. |
| Защита от повтора | `ui/hooks.ts` (`useAction({ exclusive })`) | Только для действий, повтор которых создаёт запись. |
| Второй тап двойного касания | `ui/tapGuard.ts` | Тап по элементу управления в ту же точку (24 px) в течение 350 мс по **другому** элементу (или тот же узел с другой надписью) не доходит до приложения: первый тап поменял то, что под пальцем (кнопка шага, исчезнувший лист, открывшийся экран). Окно отсчитывается от последнего тапа, продлевается погашенными и начинается заново, когда действие закончилось (`tapSettled` из `useAction` и подтверждения). Тот же элемент — проходит (степперы, чипы); тап мимо элементов ничего не «заряжает»; клавиатура, VoiceOver и клики из кода — проходят; клик метки по своему полю и метка отклика iPhone — часть того же тапа. Действия на отпускание пальца (не клик) сторож не видит — им своя проверка. |
| Лист по значению | `ui/lazy.tsx` (`SheetFor`) | Не `{x && <Sheet opened />}` — такой лист исчезает без анимации, и следующий тап падает в то, что под ним. `SheetFor` держит значение, пока лист уезжает, и каждое открытие делает новым листом (не уходящий со старым состоянием). |
| Закрывающиеся окна | `ui/theme.ts` (`POP_OUT`, `SHEET_OUT`) | Окно или лист, который закрывается, не принимает нажатий (`pointer-events: none` в стилях ухода Mantine), подложка под ним ловит тап — ни его кнопка, ни экран под ним не сработают второй раз. Кнопка подтверждения (`ConfirmModal`) после успеха остаётся занятой до нового открытия. |

Распознавание жестов сделано вручную по идеям pmndrs/use-gesture (порог, фиксация оси, захват указателя, отличие тапа
от перетаскивания, отмена) — библиотека жестов не подключена: жестов немного, у каждого своя связь со стеком и
скроллом. Листы (нижние окна) пока на Mantine + `ui/sheetSwipe.ts`; при их переделке сравнить с Vaul (стандарт
Эмиля Ковальски для листов) и с Motion.

### Проверка на iPhone

- Живая сборка — GitHub Pages из `main`: https://neyron357-boop.github.io/MyGarage-/ (её открывают и PWA, и Telegram).
- Ветка до слияния — локально: `npm run build && npm run preview -- --host`, на iPhone в той же Wi-Fi —
  `http://<IP компьютера>:4173`. Без HTTPS не работают камера в некоторых режимах, буфер обмена, установка PWA и Telegram.
- Видео жестов: `node e2e/gestures.cjs <папка> <метка>` записывает одинаковые жесты касаниями (панель вкладок и др.)
  кадрами экрана (30 к/с) с замерами — где была линза относительно пальца, какие переходы случились. Чтобы «до» и
  «после» были в равных условиях, обе версии собираются одним способом: `npm run build:single` (прежняя — из
  `git worktree` на `main`), запись — с `BASE_URL=file:///…/dist-single/index.html`. Затем
  `node e2e/gesture-player.cjs <папка> до после` собирает одну страницу: оба прогона рядом, синхронно, с паузой,
  перемоткой и замедлением ×0,25 (ffmpeg не нужен).
- На телефоне смотреть: панель вкладок (прижать, вести медленно, замереть, вернуться, отпустить; быстрый проход;
  увести вверх и отпустить; поймать линзу на лету), «Назад» свайпом от края и его отмена, свайп строки доски,
  потянуть доску, нижние листы (тянуть вниз), клавиатура в полях, уход в фон и возврат, тёмная тема, VoiceOver,
  «Уменьшение движения».

### Задача завершена, когда

- затронутый путь пройден целиком: первое касание, действия во время работы, завершение, отмена, ошибка, возврат;
  соседние сценарии общего компонента не сломаны;
- для каждого изменённого жеста пройдена матрица (медленно, пауза, смена направления, отмена, новый захват во время
  анимации) и есть запись одинаковых жестов до и после; для логики — тест или воспроизводимый сценарий;
- ревью кода, движения (Эмиль Ковальски) и интерфейса (Impeccable) проведены, найденное исправлено или в карте;
- typecheck, `npm test`, `npm run e2e` (+ `E2E_HAPTIC_LABELS=1`), `npm run e2e:motion`, `npm run build` проходят, в консоли
  браузера нет ошибок;
- `docs/progress.md` и `docs/quality/map.md` обновлены; в отчёте — что подтверждено в браузере, в PWA и в Telegram на
  iPhone, и что ещё ждёт проверки на устройстве.
