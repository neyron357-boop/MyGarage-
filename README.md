# MyGarage

Рабочий инструмент менеджера небольшой автомастерской: клиенты, машины, приёмка с фото, оценки и согласования, запчасти, инвойсы, касса, отчёты. Интерфейс на русском и английском.

*A work tool for a small auto repair shop manager: customers, cars, photo check-in, estimates and approvals, parts, invoices, cash, reports. Russian / English UI.*

**Статус:** этап описания проекта, разработка ещё не начата.
