# MyGarage

Рабочий инструмент менеджера небольшой автомастерской в ОАЭ: клиенты и машины, пошаговая приёмка с фото и подписью, оценка в трёх блоках, согласования с клиентом, запчасти, Tax Invoice (VAT 5 %), касса, расходы, зарплаты, отчёты. Интерфейс на русском и английском.

*A work tool for a small auto repair shop manager in the UAE: customers and cars, photo check-in with signature, three-block estimates, customer approvals, parts, VAT tax invoices, cash, expenses, salaries, reports. Russian / English UI.*

## Статус

**Этап A готов: приложение работает на телефоне и ПК, данные хранятся на устройстве, работает без интернета.**
Следующий этап — облако (Supabase): синхронизация между телефоном и ПК, ссылки для клиента с кнопкой «Согласен», автоматические бэкапы. Подробно — [docs/progress.md](docs/progress.md).

## Запуск на своём компьютере

Нужен Node.js 20+ ([nodejs.org](https://nodejs.org)).

```bash
cd app
npm install
npm run build      # собрать рабочую версию (папка app/dist)
npm run preview    # открыть http://localhost:4173
```

В Chrome или Edge в адресной строке появится значок «Установить» — приложение откроется отдельным окном, будет работать без интернета, данные хранятся в этом браузере.

Для разработки: `npm run dev` → http://localhost:5173.

## Установка на телефон

Браузер разрешает установить приложение и работать офлайн только по адресу **https://…** (или `localhost` на самом компьютере).

- **Попробовать с телефона в той же Wi-Fi сети:** `npm run build && npm run preview -- --host` и откройте на телефоне адрес вида `http://192.168.x.x:4173`. Приложение работает, но без установки и офлайн-режима — вверху будет предупреждение «Открыто без HTTPS».
- **Для работы:** выложите папку `app/dist` на любой статический хостинг с HTTPS — это только файлы приложения, данные остаются на телефоне:
  - **GitHub Pages:** в репозитории Settings → Pages → Source: *GitHub Actions*, затем Actions → *Deploy to GitHub Pages* → *Run workflow* (для приватного репозитория нужен платный тариф GitHub);
  - **Netlify Drop:** перетащите папку `app/dist` на [app.netlify.com/drop](https://app.netlify.com/drop).

  Затем откройте адрес на телефоне: **Android (Chrome)** — «Установить приложение»; **iPhone (Safari)** — «Поделиться» → «На экран Домой». Только установленное приложение защищено от автоматической очистки данных браузером.

Когда выходит новая версия, приложение показывает «Доступна новая версия» — обновление применяется кнопкой, не посреди приёмки.

## Данные и резервные копии

- Попробовать без своих данных: **Настройки → Данные → Загрузить демо-данные** (8 заказов на всех этапах).
- **Резервная копия** всех данных с фото: **Настройки → Данные → Скачать резервную копию** (файл `.mygarage`). Делайте раз в неделю и храните на ПК или в Google Drive — доска напомнит, если копия старше 7 дней.
- Восстановление: **Настройки → Данные → Восстановить из файла** (читаются и старые файлы `.json`). Файл проверяется целиком до замены данных.

## Проверки

```bash
cd app
npm run typecheck
npm test           # 45 тестов: деньги, VAT, этапы, согласования, полный путь заказа, защита документов, резервная копия, SHA-256, ссылки WhatsApp/Telegram
npm run e2e        # сценарий в браузере на размере телефона (нужен запущенный npm run dev -- --port 5173)
```

Для `npm run e2e` подойдёт Chrome или Edge, уже установленный на компьютере. Если их нет — один раз скачайте браузер для тестов: `npx playwright install chromium`.
