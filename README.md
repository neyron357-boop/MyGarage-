# MyGarage

Рабочий инструмент менеджера небольшой автомастерской в ОАЭ: клиенты, машины, приёмка с фото, оценки и согласования с клиентом, запчасти, Tax Invoice (VAT 5 %), касса, расходы, отчёты. Интерфейс на русском и английском.

*A work tool for a small auto repair shop manager in the UAE: customers, cars, photo check-in, estimates and customer approvals, parts, VAT tax invoices, cash, expenses, reports. Russian / English UI.*

**Статус:** документы проекта готовы (черновик v0.1–0.2), разработка не начата — следующий шаг: этап 0 и этап 1 из [плана](docs/06-mvp-plan-and-prompts.md).
