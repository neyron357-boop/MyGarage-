# MyGarage

Рабочий инструмент менеджера небольшой автомастерской в ОАЭ: клиенты и машины, пошаговая приёмка с фото и подписью, оценка в трёх блоках, согласования с клиентом, запчасти, Tax Invoice (VAT 5 %), касса, расходы, зарплаты, отчёты. Интерфейс на русском и английском.

*A work tool for a small auto repair shop manager in the UAE: customers and cars, photo check-in with signature, three-block estimates, customer approvals, parts, VAT tax invoices, cash, expenses, salaries, reports. Russian / English UI.*

## Статус

**Этап A готов: приложение работает на телефоне и ПК, данные хранятся на устройстве.**
Следующий этап — облако (Supabase): синхронизация между телефоном и ПК, ссылки для клиента с кнопкой «Согласен», автоматические бэкапы. Подробно — [docs/progress.md](docs/progress.md).

## Запуск

```bash
cd app
npm install
npm run dev        # http://localhost:5173
```

Чтобы попробовать без своих данных: **Настройки → Данные → Загрузить демо-данные**.
Резервная копия всех данных (с фото): **Настройки → Данные → Скачать резервную копию**.

## Проверки

```bash
cd app
npm run typecheck
npm test           # 37 тестов: деньги, VAT, этапы, согласования, полный путь заказа, защита документов
npm run e2e        # сценарий в браузере на размере телефона (нужен запущенный npm run dev -- --port 5173)
```
