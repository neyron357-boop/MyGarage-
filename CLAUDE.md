# MyGarage — правила разработки

## Что это
PWA для менеджера небольшой автомастерской в ОАЭ (AED, VAT 5 %, интерфейс RU/EN).
Описание продукта — `docs/01`–`06`, текущее состояние — `docs/progress.md`.
Перед задачей читай связанный сценарий (`docs/02`), экран (`docs/03`) и данные (`docs/04`).

## Текущая архитектура (этап A — «на этом устройстве»)
- Всё приложение в `app/`: React 18 + TypeScript (strict) + Vite + Mantine 7 + React Router (HashRouter).
- Данные — IndexedDB через Dexie (`app/src/db/db.ts`), реактивное чтение — `useLiveQuery`.
- Облака пока нет: Supabase (`docs/05`) подключается следующим этапом. Новый код пиши так, чтобы
  бизнес-правила оставались в `domain/` и `services/`, а UI не обращался к таблицам в обход сервисов
  при записи — тогда замена хранилища не затронет экраны.
- PDF — `@react-pdf/renderer` (`app/src/pdf/documents.tsx`, оформление — `app/src/pdf/garage.tsx`): документы как у самой
  мастерской (её Tax Invoice и Quotation из Eaglecart) — английский + арабские подписи, шрифты Tinos (Times; латиница и
  кириллица) и Markazi Text (арабский). Арабский — отдельными блоками от английского и цифр (`BiLine`, `Ar`), иначе
  двунаправленный текст переставит номер; пробел в начале блока движок съедает — отступ или неразрывный пробел.
  Документы клиенту по умолчанию на английском (язык документов клиента/заказа — `en`).

## Структура `app/src`
- `domain/` — чистая логика без БД и UI: деньги, VAT, номера ОАЭ, телефоны, даты, позиции и согласования,
  этапы заказа, инвойсы, касса, отчёты, поиск по работам (`search.ts` — словарь RU/EN), дела «Сегодня» (`today.ts`),
  прибыль заказа (`profit.ts`), список поставщиков из Excel/CSV (`supplierSheet.ts`). Всё покрыто тестами.
- `db/` — схема Dexie и защита неизменяемых записей (хуки `guard`).
- `services/` — операции с данными (заказы, приёмка, оценка, запчасти, деньги, документы, сообщения, бэкап).
- `features/` — экраны по разделам; `ui/` — общие компоненты (`components.tsx`, `pwa.tsx` — установка и обновления,
  `device.ts` — хранилище и напоминание о копии, `ErrorBoundary`, `unsaved`, `backCloses`/`sheetSwipe` — жесты листов);
  `i18n/` — `ru.ts`, `en.ts`; `pdf/` — документы.

## Жёсткие правила
- Деньги — целые филсы (`*Fils`), никаких float. VAT — базисные пункты (500 = 5 %). Считать только через
  `domain/money.ts`, `domain/vat.ts`, `domain/items.ts`, `domain/invoice.ts`, `domain/discount.ts`. Цена, набранная
  «VAT в цене», хранит брутто (`unitGrossFils`) — VAT выделяется из неё, итог строки не «уползает» на филс.
  Скидка — строки `kind: 'discount'` (`setDiscount`); после выписки — только кредит-нота + новый инвойс (`discountIssuedInvoice`).
  В документах скидка — не строкой с минусом, а долей в колонке Discount каждой строки и строкой в итогах (`spreadDiscount`);
  на экране — одной строкой, сколько бы ставок VAT ни было под ней.
- Подписанные акты, отправленные версии оценки, решения клиента, инвойсы, оплаты, движения кассы,
  закрытия дня, долги и журнал не изменяются и не удаляются — это обеспечивают хуки в `db/db.ts`.
  Исправление — только новой записью (дополнение к акту, новая версия, кредит-нота, обратная проводка).
  Пруфы к расходам — фото в `media` со слотом `proof` (`services/proofs.ts`): запись кассы при этом не меняется.
  Единственное исключение — удаление заказа целиком без документов и денег (`deleteJob` в `services/orders.ts`,
  проверка `domain/deletion.ts`, журнал снимает только `purgeJournal`), с «Отменить» сразу после.
- Позицию можно отметить выполненной только после согласия клиента (`canMarkDone`).
  Переходы этапов — только через `changeStage` (правила в `domain/stages.ts`); закрытый/отменённый заказ возвращается
  только `reopenJob` (`canReopen` / `reopenStage`).
- Главный путь — ленивый (v0.5), для менеджера с двумя механиками: принял → что нашли → запчасти → цена клиенту →
  согласие → работа → оплата → выдал. Машина принимается по одному номеру (`checkIn`, одна кнопка «Принять») и сразу
  открывается **экран заказа** `features/job/JobPage.tsx` (`/orders/:id`): строки, одна главная кнопка по шагу, всё
  редкое — плитки под «…». Шаг заказа (`Phase`: look · price · wait · work · pay · out · debt) читается из фактов
  (`domain/flow.ts`, `phaseOf` в `services/flow.ts`), этап двигается сам (`syncStage`) — **не добавлять ручных
  переключений этапа в главный путь**. Ответ клиента — `approveAll` / `answerLines` / `refuseAll` / `dropLine`
  (версии и решения пишутся как в подробном пути); новая цена сказанной строки — тап по сумме в её листе, `repriceLine`
  (ждёт ответа → черновик с новой ценой; согласована → версия `price_change` только с ней, согласовано лично; до инвойса);
  «Готово» — `quickInvoice` (согласует оставшееся лично, отмечает
  выполненным, выписывает инвойс, заказ → «Готово»); после оплаты — «Выдать» (`closed` из любого рабочего этапа, если
  инвойс оплачен или подписан долг, либо платить не за что); «…» → «Без оплаты» — закрыть без оплаты и без долга
  (`closeUnpaid`: отметка `order.waived`, долг списан, инвойс и оплаты как были); «Оплата у главного» —
  `closeUnpaid(id, 'owner')` (`waived.via`): клиент заплатил владельцу, в кассу менеджера ничего, выручка остаётся. Акт приёмки необязателен. Подробный путь (оценка A/B/C →
  согласования → работы → проверка → выдача) — второй план: «…» → «Подробно» (`/orders/:id/details`, прежний `OrderPage`).
- Дела по всем машинам — только из фактов заказа (`domain/today.ts` → «Сегодня» на доске): новое «что сделать» —
  новый вид задачи там, не отдельный блок или подсказка. Заметки менеджера — таблица `notes` (`services/notes.ts`),
  в документы не попадают. Работа на стороне — `item.outsource` (подрядчик — поставщик с `service`), оплата
  подрядчику — `payOutsource` (расход заказа). Варианты детали — `item.offers`, условия возврата — `returnBy`/`noReturn`.
- Текста на экране — минимум: подписи из одного-двух слов, без пояснительных абзацев и подсказок под полями; состояние —
  значком и цветом (`PHASE_META` в `features/job/phase.tsx`). Новое действие на заказе — плитка в «…» (`.action-tile`)
  или состояние главной кнопки, не новая вкладка и не новый экран.
- Лимит без звонка, стоянка, плата за диагностику и «старые запчасти» убраны из приёмки и настроек; в актах, подписанных
  раньше, эти поля только показываются (UI и PDF проверяют, что поле есть).
- Клиент может быть без имени и телефона (`''`): показывать «Клиент без имени», не строить ссылки `tel:`/`t.me` без номера.
- Быстрые подсказки, чьи слова попадают в документы (жалобы, лампы, «что работает», причины без фото), — списки
  `domain/quickLists.ts` (Настройки → Списки), по умолчанию английские; в акт пишутся сами слова, старые коды показывать
  через `lightLabel`/`checkLabel`. Новые такие подсказки — туда же, не строками i18n.
- Ни одной строки интерфейса без перевода: ключи i18next, `en.ts` типизирован как `typeof ru`.
  Документы и сообщения клиенту — на языке клиента (`tFor(lang)`), не на языке интерфейса.
- Время показываем в Asia/Dubai, формат ДД/ММ/ГГГГ (`domain/dates.ts`). Телефоны — E.164, номера машин — эмират + код + номер.
- Мобильная вёрстка в первую очередь (390×844), затем ПК (1440×900). Не обрезать подписи кнопок. Касание — от 44 pt:
  маленькие кнопки (`compact-*`, `ActionIcon`, чипы, пилюли) получают невидимое поле касания сами (styles.css,
  «Touch targets»), новые мелкие нажимаемые элементы добавлять туда же.
- Вид — нативное приложение iPhone на iOS 26/27 (Liquid Glass), **живой** (v0.10, для одного занятого человека с СДВГ):
  цвет несёт смысл, слов мало. Системная палитра iOS (серый фон `--app-canvas`, белые группы с углами 24 px
  (`--radius-group`) без рамок и теней — в тёмной теме волосяной ободок света, волосяные разделители `--app-hairline`,
  подсветка нажатой строки `--app-press`). **Один акцент** — `cobalt`: по умолчанию синий iOS, выбирается на устройстве
  («Ещё → Оформление → Цвет», `ui/accent.ts`, `data-accent` на `<html>` переставляет оттенки `--mantine-color-cobalt-*`) —
  в коде акцент только через `cobalt`. **У каждого шага заказа свой цвет iOS** (`PHASE_META`: смотрим — индиго, цена —
  фиолетовый, ждём — оранжевый, в работе — синий, оплата — зелёный, выдать — мятный, долг — красный): фильтры доски,
  плашка шага в строке, залитая плашка и свечение экрана заказа. **Свечение** под крупным заголовком (`.screen-body::before`,
  `.page-shell::before`: акцент; у заказа — цвета шага, `usePhaseGlow` пишет `--glow`, без `:has()`) — градиент без размытия, рисуется
  один раз. Символы на скруглённых квадратах своего цвета, как иконки приложений (`.tile-icon` в «…», `.row-icon`,
  `.today-icon`, `.empty-icon`) — яркий оттенок `-6`; глубокий `-filled` — для белых слов на кнопках и пилюлях. Залитые
  кнопки светятся своим цветом. Кнопки, сегменты и поиск — капсулы; всё, что парит над содержимым (нижняя панель, «＋»,
  круглые кнопки шапки, меню, баннеры), — стекло (класс `.glass`, токены `--glass-*`; линза выбранной вкладки — с
  акцентом), под панелями содержимое гаснет в цвет фона (`.screen::after`, `.nav-bar::before`).
  У предков стеклянных элементов не анимировать `opacity`/`filter` (такой предок становится границей размытия —
  стекло перестаёт размывать содержимое под собой).
  Системный шрифт телефона (SF Pro / Roboto / Segoe UI) в размерах iOS (34 крупный заголовок — жирность 800, плотно;
  над ним дата или номер цветом акцента — `.page-eyebrow`; заголовки групп — 17 bold, `.group-title`, счётчик рядом —
  `.count`; 17 текст строк и кнопок, 15 вторичный, 13 подписи), крупные цифры — `--font-rounded`; тёмная тема — те же
  токены в `cssResolver`. Деньги в «Учёте» — карточки как у банка (`.money-card`), мастерская в «Ещё» — карточка с
  логотипом (`.garage-card`). Суммы — только `Money` (филсы на ступень тише, минус — «−»); сумма, о которой лист
  (приход/расход, оплата, зарплата), — `MoneyInput big`. Люди — `PersonAvatar` (инициалы на градиенте своего цвета).
  Статус заказа в списках (поиск, визиты) — `OrderStatus` / `PhaseTag` (шаг, как на доске), не `StageBadge`. Месяц —
  `MonthField` (стрелки ‹ ›), день в списке — `dayHeading` («Сегодня», «Вчера», «Понедельник, 9 ноября»).
  Шрифт Oswald — только для номерного знака (`PlateText`: раскладка своего эмирата, без гербов).
  Главное фото машины — `services/cover.ts` (`CarCover` в карточке заказа, мини-фото в строке доски).
  Ряд фото с плиткой «Фото» — `ui/PhotoStrip` (пруфы, фото строк); фото на весь экран — только `PhotoViewer`
  (в нём «Поделиться» / «Сохранить»). Доска — свежие сверху (`lastChange` в `domain/flow.ts`). Свайп строки — `ui/swipe.ts`; архив —
  отметка `archivedAt` (`archiveJob`), заказ при этом не меняется.
  Тема — только через `ui/scheme.ts` (`setSchemePref`; «Авто» — по солнцу в Дубае, `domain/daylight.ts`), не
  `setColorScheme` Mantine: тема у провайдера принудительная. Несколько строк заказа разом — `removeLines`.
  Excel финансов — только формат таблицы «Money Tracker» (`domain/moneySheet.ts` + шаблон `moneySheetTemplate.ts` из её
  файла; не менять оформление вручную). Отчёт сканера — `services/obd.ts` (pdf.js грузится только там, `services/pdfText.ts`).
- Телефон — как нативное приложение (`ui/stack.tsx`, `PhoneStack`): документ не прокручивается (`html.phone-shell`),
  у каждого экрана своя прокрутка `.screen-scroll`, нижняя панель и полосы навигации неподвижны. Стек следует истории
  браузера: новый экран въезжает справа (WAAPI), предыдущий остаётся смонтированным (скрыт, с состоянием и прокруткой) —
  «Назад» мгновенный, свайп от левого края показывает настоящий экран под пальцем; вкладки — кроссфейд; «Новый заказ»
  поднимается снизу и закрывается круглой «×». Нижняя панель — плавающая капсула вкладок (62 pt, 21 pt от краёв) и
  отдельная круглая «＋»: вкладки — разделы, не действия; новое действие на все экраны в панель не добавлять.
  «Назад» на телефоне — круглая кнопка «‹» без подписи. Прокручивать — `scrollToTop()` из `ui/stack`, не `window.scrollTo`.
  Шапка `PageHeader` и панель `StickyBar` на телефоне сами переносятся в слоты экрана (вне его прокрутки).
  Вкладки внутри экрана меняют адрес с `replace: true` (не шаги истории). `useViewportSync` держит приложение ровно в
  видимой области: с клавиатурой экран кончается над ней, нижняя панель прячется; после клавиатуры в установленном на
  iPhone приложении раскладка принудительно восстанавливается (баг WebKit — экран «укорачивался», панель висла над
  чёрной полосой). На ПК — прежний `AppShell` с прокруткой окна.
- Плавность (v0.9, 60 fps): экраны стека не перерисовываются, когда стек двигается (`Screen` — `memo`, содержимое
  создаётся один раз на место в истории, у экрана свой `LocationContext`). Чтение базы на экране — `useScreenLiveQuery`
  (спит, пока экран под другим, просыпается, когда он снова сверху), не `useLiveQuery` напрямую; «Назад» из кода —
  `useStackBack()` (`useStack()` меняется с каждым переходом). Листы и окна по касанию — `LazySheet` (не создаются, пока
  их не открыли; частый — `warm`, создаётся в простое); `ConfirmModal` и `SendDialog` ленивые сами. Строки длинных
  списков — `memo` (`JobRow`; `loadBoard` сохраняет неизменный заказ тем же объектом). Под пальцем — запись в стиль
  элемента, не состояние React (`useSwipeRow`). Без `backdrop-filter` над прокручиваемым содержимым (кроме стекла
  панелей). Замер переходов — `npm run build`, затем `node e2e/moves.cjs dist 4 [вторая сборка]` (CPU самой тяжёлой
  задачи: от касания до первого кадра).
- Тактильный отклик — только через `ui/haptics.ts`. На iPhone (iOS 18+) WebKit даёт отклик лишь на доверенное нажатие
  системного переключателя (с iOS 26.5 — только касание пользователя, не `click()` из кода), поэтому поверх кнопок,
  вкладок, чипов, шагов и фотоплиток сама кладётся прозрачная `<label for="mg-haptic">` (палец попадает в неё, кнопка
  получает клик как обычно), сегменты накрываются переключателем, флажки и переключатели Mantine сами становятся `switch`.
  Новые нажимаемые элементы — `button` с одним из классов из `TAPPABLE`; не ставить `preventDefault` на их клик.
  `haptic(kind)` из кода — только Android (вибрация). Выключается в «Ещё → Оформление» (на устройстве).
  Иконка приложения — `scripts/app-icon.cjs` (`public/icon*`, `apple-touch-icon.png`), затем стартовые экраны iPhone —
  `scripts/ios-splash.ps1` → `public/splash/`.
- Дизайн — только через тему и общие компоненты `ui/components.tsx`: `PageHeader` (крупный заголовок, на телефоне —
  стеклянные круглые кнопки шапки; действия — в `right`), `RowGroup`/`FormRow` (строки «подпись слева — значение
  справа»), `List/ListRow`, `Section`, `Kpi`, `EmptyState`, `Tip` (подсказка как TipKit), `StickyBar`, `ScrollTabs`,
  `SelectCard`, `PlateText`, `Money`, `ContactTiles` (WhatsApp / Telegram / звонок плитками), `StageBadge/StageTrack`;
  классы `.chip`/`.chip-row` (быстрый выбор), `.suggest` (подсказка «уже в базе»), `.eyebrow`.
  Никаких случайных hex-цветов, цветных полос-рамок (`borderLeft/Top`) и надписей капсом.
- Поля ввода — 16 px, вариант `filled` (задано темой): на телефоне страница не масштабируется (viewport, `touch-action`,
  жест-блок в `main.tsx`) — не делать полям `size="xs|sm"`. Подсказки Autocomplete — с `filter={typedOnly}`.
- «Новый заказ», приёмка/выдача и быстрый инвойс открываются без нижней панели (фокус-режим в `App.tsx`).
- Движение — только готовыми классами из `styles.css` (`page-enter`, `fade-enter`, `rise-enter`, `step-next/prev`,
  `pop-in`, `stagger`, `tap`) и токенами `--ease-ios` (всё, что едет: экраны, листы), `--spring` (кнопки, чипы — сжатие
  80 мс, пружина назад), `--ease-out`, `--dur-1..3`; при `prefers-reduced-motion` всё отключается само (и переходы экранов).
  Окна на телефоне — нижние листы (тема `phoneTheme`, кривая iOS 440 мс); загрузка экрана — `PageSkeleton`, не `return null`.
- Жесты и движение списков (v0.8) — только общими средствами: свайп строки — `ListRow` с `trailing` / `leading`
  (`ui/swipe.ts`, `SwipeSpec`; действие без «Отменить» — `full: false`, чтобы длинный свайп только открывал кнопку);
  строки, которые появляются, уходят и меняются местами, — `<List animate>` (`ui/motion.ts`, `useAutoAnimate`); сумма,
  которая меняется на глазах, — `<Money roll>`; отметка завершённого момента (оплачено, выдана) — `celebrate()`.
  Вкладки раздела, которые листаются свайпом, — `useTabSwipe` (`ui/tabSwipe.ts`; не там, где у строк свои свайпы по всей ширине).
  Путь заказа — `PhaseTrack`. Новые анимации — transform/opacity, без раскладки каждый кадр; у предков стекла — только transform.
- Необратимое действие (выписка инвойса, замена данных из копии) — через `ConfirmModal` (действие во всю ширину, «Отмена»
  под ним);
  удаление черновика — с «Отменить» (`undoToast`). Формы с кнопкой «Сохранить» отмечают несохранённое (`useMarkUnsaved`).
- Только то, что работает и без HTTPS: `uid()` из `db.ts`, `sha256Hex` из `services/media.ts`, `copyText` из `ui/clipboard.ts`
  (по http в локальной сети `crypto.randomUUID`, `crypto.subtle` и `navigator.clipboard` недоступны).
- Новая таблица Dexie — только новой версией схемы (`this.version(n+1)`), с миграцией данных при необходимости.

## Команды (в `app/`)
- `npm install` — зависимости
- `npm run dev` — разработка (http://localhost:5173)
- `npm run typecheck` — TypeScript
- `npm test` — unit + сквозные тесты сервисов (fake-indexeddb)
- `npm run e2e` — браузерный сценарий целиком (нужен запущенный `npm run dev -- --port 5173`); скриншоты в `test-results/`.
  Браузер — Chromium из Playwright, если установлен (`npx playwright install chromium`), иначе Chrome или Edge с компьютера;
  выбрать явно — `E2E_BROWSER=chromium|chrome|msedge`
- `npm run e2e:motion` — стек телефона: переход, «Назад» с сохранённой прокруткой, свайп с экраном под пальцем,
  короткий свайп, вкладки, «Новый заказ» снизу, неподвижная панель, документ не прокручивается, нет переполнения вширь,
  во вкладке Safari край отдан свайпу Safari;
  `E2E_HAPTIC_LABELS=1 npm run e2e` — весь сценарий с метками отклика iPhone поверх кнопок (ничего не должно сломаться);
  `npm run shots` — скриншоты главных экранов телефона (светлая и тёмная тема) и ПК в `test-results/design/` для просмотра дизайна;
  `npm run moves` — после `npm run build`: CPU переходов (заказ, лист, «Назад», вкладки, «Новый заказ») при замедлении ×4;
  сравнить две сборки — `node e2e/moves.cjs dist 4 <другая папка сборки>`
- `npm run build` — PWA для хостинга (`dist/`); `npm run preview` — открыть сборку на http://localhost:4173
- `npm run build:single` — один файл `dist-single/index.html` для превью
