# MyGarage — правила разработки

## Что это
PWA для менеджера небольшой автомастерской в ОАЭ (AED, VAT 5 %, интерфейс RU/EN).
Описание продукта — `docs/01`–`06`, текущее состояние — `docs/progress.md`.
Перед задачей читай связанный сценарий (`docs/02`), экран (`docs/03`) и данные (`docs/04`).

## Текущая архитектура (этап A — «на этом устройстве»)
- Всё приложение в `app/`: React 18 + TypeScript (strict) + Vite + Mantine 7 + React Router (HashRouter).
- Данные — IndexedDB через Dexie (`app/src/db/db.ts`), реактивное чтение — `useLiveQuery`.
- Облака пока нет: Supabase (`docs/05`) подключается следующим этапом. Новый код пиши так, чтобы
  бизнес-правила оставались в `domain/` и `services/`, а UI не обращался к таблицам в обход сервисов
  при записи — тогда замена хранилища не затронет экраны.
- PDF — `@react-pdf/renderer` (`app/src/pdf/documents.tsx`), шрифт Noto Sans (латиница + кириллица).

## Структура `app/src`
- `domain/` — чистая логика без БД и UI: деньги, VAT, номера ОАЭ, телефоны, даты, позиции и согласования,
  этапы заказа, инвойсы, касса, отчёты. Всё покрыто тестами.
- `db/` — схема Dexie и защита неизменяемых записей (хуки `guard`).
- `services/` — операции с данными (заказы, приёмка, оценка, запчасти, деньги, документы, сообщения, бэкап).
- `features/` — экраны по разделам; `ui/` — общие компоненты (`components.tsx`, `pwa.tsx` — установка и обновления,
  `device.ts` — хранилище и напоминание о копии, `ErrorBoundary`, `unsaved`, `backCloses`/`sheetSwipe` — жесты листов);
  `i18n/` — `ru.ts`, `en.ts`; `pdf/` — документы.

## Жёсткие правила
- Деньги — целые филсы (`*Fils`), никаких float. VAT — базисные пункты (500 = 5 %). Считать только через
  `domain/money.ts`, `domain/vat.ts`, `domain/items.ts`, `domain/invoice.ts`.
- Подписанные акты, отправленные версии оценки, решения клиента, инвойсы, оплаты, движения кассы,
  закрытия дня, долги и журнал не изменяются и не удаляются — это обеспечивают хуки в `db/db.ts`.
  Исправление — только новой записью (дополнение к акту, новая версия, кредит-нота, обратная проводка).
- Позицию можно отметить выполненной только после согласия клиента (`canMarkDone`).
  Переходы этапов — только через `changeStage` (правила в `domain/stages.ts`).
- Главный путь — быстрый (v0.3): машина принимается по одному номеру (`checkIn` в `services/orders.ts`, одна транзакция;
  имя и телефон клиента необязательны и дописываются позже); в приёмке нет обязательных полей (`completeInspection` —
  сохранить без подписи; подпись по желанию замораживает акт); `quickInvoice` в `services/money.ts` — черновые позиции
  согласуются «лично», отмечаются выполненными, выписывается инвойс, заказ → «Готово»; после оплаты — «Выдать и закрыть»
  (`closed` разрешён из любого рабочего этапа, если инвойс выписан и оплачен или подписан долг). Подробный путь
  (оценка → согласования → работы → проверка → выдача) остаётся вторым планом.
- Лимит без звонка, стоянка, плата за диагностику и «старые запчасти» убраны из приёмки и настроек; в актах, подписанных
  раньше, эти поля только показываются (UI и PDF проверяют, что поле есть).
- Клиент может быть без имени и телефона (`''`): показывать «Клиент без имени», не строить ссылки `tel:`/`t.me` без номера.
- Ни одной строки интерфейса без перевода: ключи i18next, `en.ts` типизирован как `typeof ru`.
  Документы и сообщения клиенту — на языке клиента (`tFor(lang)`), не на языке интерфейса.
- Время показываем в Asia/Dubai, формат ДД/ММ/ГГГГ (`domain/dates.ts`). Телефоны — E.164, номера машин — эмират + код + номер.
- Мобильная вёрстка в первую очередь (390×844), затем ПК (1440×900). Не обрезать подписи кнопок.
- Вид — «светлый, как iOS»: серый фон `--app-canvas`, белые группы без рамок и теней, один синий акцент (`cobalt`
  в `ui/theme.ts` = системный синий iOS), системный шрифт телефона (SF Pro / Roboto / Segoe UI), крупный заголовок экрана;
  тёмная тема — те же токены в `cssResolver`. Шрифт Oswald — только для номерного знака (`PlateText`).
- Дизайн — только через тему и общие компоненты `ui/components.tsx`: `PageHeader` (полупрозрачная полоса навигации +
  крупный заголовок, действия — в `right`), `RowGroup`/`FormRow` (строки «подпись слева — значение справа»),
  `List/ListRow`, `Section`, `Kpi`, `EmptyState`, `StickyBar`, `ScrollTabs`, `SelectCard`, `PlateText`, `Money`,
  `StageBadge/StageTrack`; классы `.chip`/`.chip-row` (быстрый выбор), `.suggest` (подсказка «уже в базе»), `.eyebrow`.
  Никаких случайных hex-цветов, цветных полос-рамок (`borderLeft/Top`) и надписей капсом.
- Поля ввода — 16 px, вариант `filled` (задано темой): на телефоне страница не масштабируется (viewport, `touch-action`,
  жест-блок в `main.tsx`) — не делать полям `size="xs|sm"`. Подсказки Autocomplete — с `filter={typedOnly}`.
- «Новый заказ», приёмка/выдача и быстрый инвойс открываются без нижней панели (фокус-режим в `App.tsx`).
- Движение — только готовыми классами из `styles.css` (`page-enter`, `fade-enter`, `rise-enter`, `step-next/prev`,
  `pop-in`, `stagger`, `tap`) и токенами `--ease-out`, `--dur-1..3`; при `prefers-reduced-motion` всё отключается само.
  Окна на телефоне — нижние листы (тема `phoneTheme`); загрузка экрана — `PageSkeleton`, не `return null`.
- Необратимое действие (выписка инвойса, замена данных из копии) — через `ConfirmModal`;
  удаление черновика — с «Отменить» (`undoToast`). Формы с кнопкой «Сохранить» отмечают несохранённое (`useMarkUnsaved`).
- Только то, что работает и без HTTPS: `uid()` из `db.ts`, `sha256Hex` из `services/media.ts`, `copyText` из `ui/clipboard.ts`
  (по http в локальной сети `crypto.randomUUID`, `crypto.subtle` и `navigator.clipboard` недоступны).
- Новая таблица Dexie — только новой версией схемы (`this.version(n+1)`), с миграцией данных при необходимости.

## Команды (в `app/`)
- `npm install` — зависимости
- `npm run dev` — разработка (http://localhost:5173)
- `npm run typecheck` — TypeScript
- `npm test` — unit + сквозные тесты сервисов (fake-indexeddb)
- `npm run e2e` — браузерный сценарий целиком (нужен запущенный `npm run dev -- --port 5173`); скриншоты в `test-results/`.
  Браузер — Chromium из Playwright, если установлен (`npx playwright install chromium`), иначе Chrome или Edge с компьютера;
  выбрать явно — `E2E_BROWSER=chromium|chrome|msedge`
- `npm run build` — PWA для хостинга (`dist/`); `npm run preview` — открыть сборку на http://localhost:4173
- `npm run build:single` — один файл `dist-single/index.html` для превью

## Определение «готово»
- typecheck, `npm test` и `npm run e2e` проходят, в консоли браузера нет ошибок;
- изменённые экраны проверены на скриншотах телефона и ПК;
- `docs/progress.md` обновлён; если поведение отличается от `docs/01`–`05` — документ поправлен.
