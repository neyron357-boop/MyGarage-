# Замечания по интерфейсу (временный инструмент разработчика, v0.39)

Карандаш на экране: днём — нажал на то, что не так, написал два-три слова, сохранил; вечером — один ZIP для AI-агента.

## Как пользоваться

- **Карандаш** (круглая кнопка у края экрана): касание — режим замечаний; удержание (на ПК — правый клик) —
  «Мои замечания»; потянуть — переставить вдоль края (место запоминается).
- **Режим замечаний** — красная рамка по краю экрана. Приложение под ним ничего не делает (касание не нажимает кнопку,
  не открывает поле), но прокручивается. Касание по элементу — рамка на нём и лист замечания:
  «Шире» / «Уже» — взять то, что вокруг, или вернуть меньшее; готовые слова чипами («Не работает», «Убрать»…) или свои;
  «Сохранить» — и приложение снова как обычно. Снимок экрана делается сам, рамка №1 — вокруг выбранного элемента.
- **«Отметки»** (или касание по маленькому снимку) — рамка, стрелка, номерная метка; у каждой — пара слов; «Просмотр» —
  ровно так, как уйдёт в экспорт.
- **«Весь экран»** — замечание без элемента: снимок и отметки на нём.
- **«Мои замечания»** — список (новые / исправлены / все); касание — открыть: поправить слова и отметки, заменить снимок
  фото из телефона, «Исправлено», «Удалить». Кружок слева — выбрать для экспорта (сначала выбраны все новые).
- **«Экспорт для агента»** — ZIP: `TASKS.md` (задачи по номерам, слова как написаны), `screenshots/NNN.png` (снимки с
  отметками; номер файла = номер задачи), `annotations.json` (маршрут, селектор, координаты, размер экрана). Потом
  «Поделиться» (AirDrop, Telegram, «Сохранить в Файлы») или «Скачать» на ПК. Замечания после экспорта остаются.

## Включить и выключить

- На устройстве: «Ещё → Оформление → Кнопка замечаний» (или «…» в «Моих замечаниях» → «Скрыть кнопку ✎»).
- Совсем, при сборке: `VITE_FEEDBACK=off npm run build` — карандаша нет ни у кого.
- Тесты (`e2e/*.cjs`) прячут карандаш на своём устройстве (`mygarage.feedback = 0`); свой шаг в `smoke.cjs` его включает.

## Где что

- Всё здесь, в `src/devtools/feedback/`; своя база IndexedDB `mygarage-feedback` (замечания, снимки JPEG) — данные
  мастерской (`mygarage`) не трогаются, в резервную копию не входят.
- Приложение знает об инструменте двумя строками: `<FeedbackTool />` в `App.tsx` и `<FeedbackSwitchRow />` в
  `ui/Appearance.tsx`. При запуске грузится только карандаш; режим, редактор, список и библиотека снимков — при первом
  касании карандаша.
- Снимок — `modern-screenshot` (страница копируется в SVG и рисуется на холсте; только видимое, прокрутка сохраняется).

## Как удалить полностью

1. Удалить папку `src/devtools/feedback/`.
2. Убрать две строки импорта и два тега из `App.tsx` и `ui/Appearance.tsx`.
3. `npm uninstall modern-screenshot`; убрать строки `mygarage.feedback` из `e2e/*.cjs` и шаг «v0.39» из `smoke.cjs`.
4. (Необязательно) на устройствах останется пустая база `mygarage-feedback` — её можно удалить в настройках браузера.

## Ограничения

- На iPhone страница не может сфотографировать свой экран системно: снимок рисуется из самой страницы. Размытие
  «стекла» (backdrop-filter) в снимке не видно, 3D-машина Job card (WebGL) может выйти пустой, прилипшие заголовки
  уходят вместе с прокруткой. Если снимок не получился (старый Safari не отдаёт такой холст) — «Из галереи»: снимок,
  сделанный кнопками телефона; если он той же формы, что экран, рамка элемента встанет сама.
- Клавиатура на iPhone открывается сразу по касанию элемента, только когда снимок уже готов (обычно — через долю секунды
  после входа в режим); иначе поле ждёт снимка и открывается следующим касанием.
- Элемент под нижней панелью режима не выбрать — «⇅» переносит панель наверх.
- Имена React-компонентов в `annotations.json` есть только при `npm run dev`: в собранном приложении их нет.
- Данные живут в браузере устройства: «Очистить данные сайта» стирает и замечания. Экспортируйте вовремя.
