# Прогресс разработки

> Обновлено: 2026-11-06

## Этап A — «на этом устройстве» — ГОТОВ

Приложение полностью работает в браузере телефона или ПК. Данные (включая фото и PDF) хранятся на устройстве в IndexedDB. Облако подключается следующим этапом (раздел «Дальше»).

### Проверки
- `npm test` — 37 тестов: деньги, VAT и округление, номера и телефоны, даты в Дубае, позиции и согласования, этапы, инвойсы, касса, отчёты, полный путь заказа через базу, защита подписанных документов от изменения, одновременное открытие приёмки, переводы.
- `npm run e2e` — сценарий в браузере на экране телефона: демо-данные → новый клиент → приёмка с 8 фото, повреждением, подписью → оценка из шаблона с подсказкой → согласование лично с подтверждением → работы → контроль качества → выдача с инвойсом и оплатой → закрытие → претензия → касса, расходы, отчёты, настройки. Ошибок в консоли нет.
- PDF проверены: кириллица и латиница, фото, подпись, суммы.

### Отличия от плана (docs/05–06)
| План | Сейчас | Почему |
|---|---|---|
| Supabase с первого этапа | данные на устройстве (IndexedDB), облако — следующий этап | аккаунтов пока нет; приложение уже можно использовать и тестировать |
| Ссылка для клиента с кнопками «Согласен / Отказ» | клиент отвечает в WhatsApp/Telegram, менеджер записывает ответ; способ и время сохраняются | ссылке нужен сервер |
| Время событий ставит сервер | время устройства | сервера пока нет |
| Вход по паролю и PIN, роли | один пользователь без входа | появится вместе с облаком |
| Платная стоянка начисляется автоматически | флажок и счётчик дней есть, сбор добавляется вручную позицией «Сбор» | достаточно для старта |
| Переводы в `ru.json` / `en.json` | `ru.ts` / `en.ts` | совпадение ключей проверяет компилятор |
| TanStack Query | `useLiveQuery` (Dexie) | данные локальные, экраны обновляются сами |
| ESLint | пока нет | TypeScript strict + тесты |

### Важно знать сейчас
- **Одно устройство.** Телефон и ПК пока не синхронизируются. Работайте на одном основном устройстве (телефон).
- **Резервная копия раз в неделю:** Настройки → Данные → «Скачать резервную копию» (файл с фото). Храните на ПК или в Google Drive.
- **iPhone:** добавьте приложение на экран «Домой» — так Safari не удалит данные.
- **Тексты актов и гарантии** — в Настройки → Тексты. Покажите владельцу; образец Tax Invoice — бухгалтеру.
- **Стартовый прайс примерный** — замените цены в Настройки → Прайс.
